# ExpenseFlow

A .NET 10 starter generated in the same general structure and startup pattern as Zeelead.

## Projects

- `ExpenseFlow.Api`
- `ExpenseFlow.Application`
- `ExpenseFlow.Domain`
- `ExpenseFlow.Infrastructure`

## Foundation

- MySQL + Entity Framework Core
- JWT authentication
- User / Role / Permission / RolePermission
- Middleware
- Seeder
- MediatR
- Serilog
- Swagger + Scalar
- Arabic / English localization
- Rate limiting
- EasyDatabaseManager
- QuestPDF
- File / Excel / Email / Token service folders

Database table classes are kept under `ExpenseFlow.Domain/Model`.
